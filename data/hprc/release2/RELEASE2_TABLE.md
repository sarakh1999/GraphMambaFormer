# HPRC Release 2 — raw sequencing download tables

Generated by `scripts/hprc/build_release2_table.py` from the official Release-2 index CSVs.

Filters applied (matched to the GraphMambaFormer long-read pipeline, which consumes **unaligned BAM** directly):

- **HiFi**: `instrument_model == Revio` and `filetype == bam`
- **ONT**: `sequencing_chemistry == R1041` and `filetype == bam`
- **Illumina**: per-sample WGS `cram` (or `fastq` fallback)
